Ejercicio 03: ¿Está en el rango 100-300?

Instrucciones

En este ejercicio, vamos a comprobar si un número se encuentra dentro del rango de 100 a 300 (incluidos)

Usaremos el operador lógico && (AND) para verificar que el número sea mayor o igual a 100 y menor o igual a 300
